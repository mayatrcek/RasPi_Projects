Core Electronics
ComponentQtyNotes
WS2812B LED strips, 144 LEDs/m, 5V — 0.5m segments essential 6 × 0.5m Six pre-cut 0.5m segments of the 144/m (high-density) variant — one per row, 72 LEDs each (432 total). Get IP30 (no coating) — IP65 silicone diffuses unevenly. Check the data-direction arrows all point the same way so the six can be chained S1→S6.
USB mini condenser microphone essential 1 Any small USB desk mic (~$8–15 on Amazon). Plug-and-play on Raspberry Pi OS. Place near the speaker for best pickup.
5V 12A power supply essential 1 432 LEDs at 30% brightness ≈ 4A; your 12A unit gives generous headroom all the way up to full brightness. Never power strips from the Pi.
470Ω resistor essential 1 Placed on the data wire between GPIO18 and the first LED. Damps signal reflections that cause LED glitches.
1000µF 6.3V electrolytic capacitor essential 2 One across the +5V/GND rails at the first LED (S1); one at the midpoint power injection point (S4 start). At 144/m density the higher current draw makes midpoint injection worthwhile.
18 AWG hookup wire (red / black) + 22 AWG (yellow for data) ~2 m 18 AWG for all power runs. 22 AWG is fine for the data signal. Twist power pairs to reduce EMI flicker.

⚡ Power Warning
Never power LED strips from the Pi's 5V or GPIO header pins — the Pi can source only ~2.5A total. Always connect strip power directly to the PSU. The Pi shares only the GND reference with the PSU.
Panel Arrangement — 0.5m × ~9cm

6 parallel strips of 72 LEDs with ~15mm centre-to-centre spacing (~5mm gap between strip edges). Data is chained end-to-end (DOUT → DIN) so all 432 LEDs are addressable from a single GPIO pin.

📏 Strip Spacing

~5mm gap between strip edges gives ~15mm centre-to-centre. The compact 9cm height means the panel looks like a dense grid — especially effective with the acrylic diffuser.

🔗 Data Chaining

Connect S1 DOUT → S2 DIN → ... → S6 DIN. All 432 pixels are addressed as one continuous strip from GPIO18.

⚡ Power Inject

Run +5V and GND from the PSU to the start of S1 and to the start of S4 (midpoint). At 144/m density this prevents colour shift at the far end under load.

🎨 Diffuser Depth

With strips this close, even 10–15mm of diffuser depth blends the rows smoothly. 20mm is the sweet spot — go deeper and you lose some brightness for no extra gain at this density.

Connection Diagram
Step-by-Step
  • 1
    PSU → LED power: Run 18 AWG red wire from PSU +5V to the +5V pad at the very start of S1, and again at the join between S3 and S4 (power injection). Mirror both runs with black GND wire.
  • 2
    Capacitors: Solder a 1000µF cap (positive leg to +5V, negative to GND) directly across the power pads at S1 and at the S3/S4 midpoint. Confirm polarity before soldering — reverse polarity destroys the cap.
  • 3
    Data signal: Pi GPIO18 (pin 12) → 470Ω resistor → S1 DIN. Keep this wire as short as practical. Then S1 DOUT → S2 DIN → ... → S6 DIN to chain all strips.
  • 4
    Shared GND: Connect a wire from Pi GND (e.g. pin 6) to the PSU GND rail. Critical — without this, the data signal has no voltage reference and LEDs will behave erratically.
  • 5
    USB microphone: Plug into any USB-A port. Verify detection with arecord -l — you should see it listed as "card 1" or similar.
⚡ Before powering on
Double-check that PSU GND and Pi GND share a common wire. Also confirm the capacitor polarity — reverse polarity will destroy it.
Software Installation
  • 1
    Flash Raspberry Pi OS Lite (64-bit) to your microSD using Raspberry Pi Imager. In the imager settings (gear icon), enable SSH and set your WiFi SSID/password before writing.
  • 2
    SSH in and update:
    sudo apt update && sudo apt upgrade -y sudo apt install -y python3-pip python3-dev git \ libatlas-base-dev portaudio19-dev
  • 3
    Install Python libraries:
    sudo pip3 install rpi_ws281x pyaudio numpy scipy RPi.GPIO
  • 4
    Disable onboard audio — it conflicts with GPIO18 PWM (used by LEDs). Edit /boot/config.txt:
    sudo nano /boot/config.txt # Find the audio line and change it to: dtparam=audio=off # Save with Ctrl+O, exit with Ctrl+X, then reboot: sudo reboot
  • 5
    Verify USB mic is detected:
    arecord -l # Expect: card 1: Device [USB Audio Device]... # Quick 3-second test recording: arecord -D hw:1,0 -d 3 -f cd /tmp/test.wav && aplay /tmp/test.wav
  • 6
    Test your LED strip is wired correctly — run this one-shot test as root:
    sudo python3 - << 'EOF' from rpi_ws281x import PixelStrip, Color strip = PixelStrip(432, 18, 800000, 10, False, 60, 0) strip.begin() for i in range(strip.numPixels()): strip.setPixelColor(i, Color(0, 50, 50)) # teal strip.show() print("LEDs on — Ctrl+C to exit") import time; time.sleep(30) EOF
    All 432 LEDs should glow teal. If only some light up, check your power connection at S1.
📁 Save & Run
Save as ~/led_wall.py — run with sudo python3 ~/led_wall.py.
📊 Spectrum Bars

72 frequency columns across the X-axis. Each bar grows upward on the Y-axis based on that band's amplitude — green at low levels, yellow at mid, red at peak.

#!/usr/bin/env python3 # LED Wall — Spectrum Visualiser # 6 strips × 72 LEDs = 432 total · 0.5m × 30cm panel # Wiring: USB mic into Pi USB · GPIO18 → LED DIN # Run: sudo python3 led_wall.py import pyaudio, numpy as np, colorsys from rpi_ws281x import PixelStrip, Color # ── LED CONFIG ──────────────────────────────────────── LED_COUNT = 432 # 6 strips × 72 LEDs LED_PIN = 18 # GPIO18 (PWM0) LED_FREQ_HZ = 800000 LED_DMA = 10 LED_BRIGHTNESS = 80 # 0–255 · keep ≤100 for power/heat LED_INVERT = False LED_CHANNEL = 0 # ── PANEL DIMENSIONS ────────────────────────────────── COLS = 72 # LEDs per strip (x-axis, 0.5m) ROWS = 6 # number of strips (y-axis, 30cm) # ── AUDIO CONFIG ────────────────────────────────────── CHUNK = 1024 RATE = 44100 CHANNELS = 1 FORMAT = pyaudio.paInt16 MIC_INDEX = None # None = auto · set to 1 if auto fails # ── GLOBALS ─────────────────────────────────────────── noise_floor = 50 # raise to 80–100 if LEDs react to silence # ── INIT ────────────────────────────────────────────── strip = PixelStrip(LED_COUNT, LED_PIN, LED_FREQ_HZ, LED_DMA, LED_INVERT, LED_BRIGHTNESS, LED_CHANNEL) strip.begin() # ── HELPERS ─────────────────────────────────────────── def hsv(h, s, v): r, g, b = colorsys.hsv_to_rgb(h, s, v) return Color(int(r*255), int(g*255), int(b*255)) def get_fft(data): s = np.frombuffer(data, dtype=np.int16).astype(float) fft = np.abs(np.fft.rfft(s, n=CHUNK)) / 512.0 return np.maximum(fft - noise_floor, 0) def clamp(x): return min(1.0, x) def clear(): for i in range(strip.numPixels()): strip.setPixelColor(i, Color(0,0,0)) strip.show() def pixel(col, row): # row 0 = S1 (top strip), row 5 = S6 (bottom strip) return row * COLS + col # ── SPECTRUM BARS ──────────────────────────────────── # 30 frequency bands along X. Bar height (Y) = amplitude. # Colour: green (quiet) → yellow → red (loud) from bottom up. def mode_spectrum_bars(fft): max_bin = len(fft) for c in range(COLS): # Quadratic (log-ish) frequency mapping — more bass columns lo = int((c / COLS) ** 2 * max_bin) hi = int(((c + 1) / COLS) ** 2 * max_bin) hi = max(hi, lo + 1) energy = np.mean(fft[lo:hi]) if hi <= max_bin else 0 bar_h = round(clamp(energy / 150) * ROWS) # 0–6 rows lit for r in range(ROWS): row_from_bottom = ROWS - 1 - r # 0=bottom(S6), 5=top(S1) if row_from_bottom < bar_h: # hue: 0.33=green at bottom, 0=red at top hue = 0.33 * (1 - row_from_bottom / (ROWS - 1)) strip.setPixelColor(pixel(c, r), hsv(hue, 1.0, 1.0)) else: strip.setPixelColor(pixel(c, r), Color(0,0,0)) strip.show() # ── MAIN LOOP ───────────────────────────────────────── p = pyaudio.PyAudio() stream = p.open(format=FORMAT, channels=CHANNELS, rate=RATE, input=True, input_device_index=MIC_INDEX, frames_per_buffer=CHUNK) print("🎵 LED Wall running · spectrum visualiser") print(" 72 frequency bands · 6 rows amplitude · Ctrl+C to quit") try: while True: data = stream.read(CHUNK, exception_on_overflow=False) fft = get_fft(data) mode_spectrum_bars(fft) except KeyboardInterrupt: print("\nShutting down...") clear() stream.stop_stream() stream.close() p.terminate()
🎛️ Tuning the sensitivity
Bars too short? Lower the divisor in clamp(energy / 150) — try / 80. Reacting to silence? Increase noise_floor from 50 up to 80–120. These two values get you dialled in for any room and speaker volume.
💡 Next ideas once it's working
Add peak-hold dots: track the highest lit row per column and hold it for ~20 frames before it falls, for a classic VU meter feel. Try scipy.signal.savgol_filter on the band values for a smoother, less jittery response. Experiment with the frequency scale exponent — change ** 2 to ** 1.5 for more treble columns.
